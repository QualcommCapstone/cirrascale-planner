## Qualcomm Inc. - AI100 powered Prompt-to-Plan Travel Planner with Visual Itineraries and Personalized Recommendations

**Proposer:** Emma Lacey (elacey@qti.qualcomm.com)
**Project Contact:** Rohit Mann (rohimann@qti.qualcomm.com)

### Project Description
Build a travel planning system where a user enters a natural-language prompt (e.g., "I want a beach vacation for 5 days, relaxed pace, great food"), and the system generates:

- a structured itinerary (day-by-day),
- a visual itinerary board (images per day/activity) using an image model, and
- personalized recommendations using embeddings + retrieval based on a user's past trips/preferences.

The capstone emphasizes a practical, end-to-end pipeline: preference capture → retrieval/ranking → itinerary generation → visual presentation → iteration/refinement.

### Student Learning Goals
- End-to-end applied GenAI system building: retrieval + ranking + generation + UI.
- Practical experience with embeddings, vector search, evaluation, and safety constraints.

### Deliverables
Final system and deliverables published on GitHub.

### Desired Background
**Skills needed:** Python, building REST APIs (FastAPI/Flask or Node), basic ML concepts (embeddings, similarity search, ranking), web app development, data ingestion + normalization.

**Nice to have:** LLM orchestration (prompting, tool/function calling, evaluation), vector DB experience, UI/UX for itinerary visualization.

In-person

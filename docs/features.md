Everything we want to build and where it stands. Anyone can add a row or
update a status through a PR. Details and tasks live in the linked Jira epic.

**Status:** `Planned` → `In progress` → `Done`
**Core-Feature:** `Yes` means a must-have; the project isn't complete without it.
